  regression was established. Add benchmarks only in response to a concrete
  performance question.
- **Additional broad range property tests**: rejected as duplicate coverage.
  Existing model tests include negative, empty, reversed, full, and
  out-of-bounds ranges and verify generator shape coverage.
- **Security remediation**: no evidenced security vulnerability or trust
  boundary exists inside this in-memory package.
- **Dependency migration**: differing `rle` pins were observed across modules,

- **Formal-verification spike**: not selected as a finding plan. It remains a
