## Findings considered and rejected

These were vetted during the audit and intentionally have no implementation
plan:

- **Recovery buffer cap and one-recovery-at-a-time behavior:** explicit,
  documented safety trade-offs rather than defects.
- **Short relay-frame passthrough:** explicitly retained by the protocol-v3
  decision; Plan 001 does not alter it.
- **Unknown valid-v3 relay types:** forward-compatible opaque forwarding is
  intentional; Plan 001 rejects only known server-authored types `0x05` and
  `0x06`.
- **JSX/SourceMap performance concerns:** no current benchmark reproduced a
  bottleneck, so optimization would violate the project's measurement gate.
- **Memo browser credentials:** explicitly local-only and excluded from the
  production Waku migration contract.
- **“JSX FFI has no tests”:** rejected as factually false; `ffi/jsx` has
  extensive contract tests.

## Audit and plan exclusions

The underlying standard audit was hotspot-weighted, not exhaustive. It did not
fully audit vendored submodule internals, every workspace package, formal proof
packages, full Playwright suites, visual/accessibility behavior, or archived
documentation. These plans do not authorize deployment, remote Cloudflare
deletion, commits beyond their execution branches, pushes, public issue edits,
or pull requests.
