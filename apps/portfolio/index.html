Apps

Canopy

An editor that understands your program, not just your characters.

コードを平坦なテキストではなく、生きた構造として扱うプロジェクショナルエディタ。入力に合わせて差分パースし、スコープと型を追跡し、式を評価して整形します。CRDT により、サーバーなしで複数人が同じ文書を同時編集できます。

  • Incremental parsing
  • CRDT
  • Projectional editing

Demo Docs Source

Loomark

An easy editor for every day.

気が散らない Markdown エディタ。Text / Preview / Split の切り替え、段落に集中する Focus Mode、日本語組版への配慮を備えます。ブラウザにローカル保存し、Google でサインインすると端末間で同期できます。

  • Markdown
  • Local-first
  • Rabbita

Source

moondsp

A text-first music editor in the browser.

ソース文書そのものが楽譜になる音楽エディタ。ビジュアルコントロールもテキストを書き換え、音は途切れずに鳴り続けます。オーディオエンジンは MoonBit 製で、Web AudioWorklet とネイティブ CLAP にコンパイルされます。

  • Audio DSP
  • Live coding
  • Wasm-GC

Demo Source

js_engine

JavaScript interpreter in MoonBit.

純 MoonBit 製の組み込み JavaScript エンジン。バイトコード実行を既定とし、未対応のソースはツリーウォーク実行にフォールバックします。native / JavaScript / Wasm / Wasm-GC で動作し、test262 で適合性を計測しています。

  • Interpreter
  • Bytecode VM
  • test262
