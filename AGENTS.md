# Agent Guidance

Prefer simple implementation that expresses only the essential complexity, eliminates accidental complexity, and contains nothing beyond what is truly necessary.

Avoid premature optimization or design for hypothetical future needs and focus on the simplest solution that works.

Keep the Agent focused on solving the problem that exists now, rather than predicting the future.

Read [docs/README.md](docs/README.md) and follow the relevant linked guidance before making changes.
